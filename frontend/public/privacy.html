Privacy Policy for OmniArch

Last Updated: October 4, 2026

Zero-Retention Policy: OmniArch processes software codebases transiently in-memory for the sole purpose of generating architecture diagrams and scaffolding code. Source code is never stored on our servers.

1. Data Handling & Security

  • Zero Code Retention: Source code parsed from GitHub or local repos is scrubbed in-memory and discarded immediately upon response completion.
  • Automated Secret Redaction: Private keys, passwords, database URIs, AWS tokens, and bearer tokens are automatically redacted prior to LLM synthesis.
  • BYOK (Bring Your Own Key): User API keys are stored only in local client storage or workflow secrets, never in centralized server databases.

2. Miro Web SDK & OAuth2

When installed on Miro boards, OmniArch requests only boards:read and boards:write permissions to place shapes and connectors on authorized boards.

3. Contact

For questions or audits, visit GitHub Repository or email support@omniarch.dev.
